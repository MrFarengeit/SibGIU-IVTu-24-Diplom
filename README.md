# Информационная система адаптивного обучения начинающих водителей
Учебный проект по разработке веб-системы, которая помогает начинающим водителям изучать материалы курса, проверять знания и отслеживать прогресс. По результатам тестирования система должна выявлять темы, требующие повторения, и предлагать связанные с ними материалы.

## Планируемые возможности
- регистрация пользователей и разграничение ролей обучающегося и администратора;
- каталог курсов, учебные материалы и видеозанятия;
- тестирование по темам и сохранение результатов;
- просмотр прогресса обучения;
- рекомендации материалов по темам, в которых обнаружены затруднения;
- управление курсами и учебным содержанием для администратора.
